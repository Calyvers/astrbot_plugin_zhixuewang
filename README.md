# 智学网 AstrBot 插件

> **v2.6.4** — 纯 HTTP 登录，t2i 图片化，LLM 工具，成绩/作业监听，答题卡批改标注渲染，手阅作业查询，逐题得分表，选择题涂色与每小题得分标注，监听推送带学生姓名

AstrBot 插件，接入智学网成绩查询系统。支持 QQ/微信等多平台。

## 服务器网络提示

> 若服务器位于中国大陆、香港、澳门、台湾以外的地区，建议检查并按需修改 `hosts`，将 `www.zhixue.com`、`ali-bg.zhixue.com` 分别指向该服务器可访问的对应节点，以减少 DNS 解析或跨境网络导致的登录、查询异常。

```text
8.212.23.202 www.zhixue.com
8.212.23.202 ali-bg.zhixue.com
```
> IP可能具有时效性与地域性差异，建议进行测试后修改。以上为测试环境下可访问的IP。

## 功能

| 功能 | 说明 |
|------|------|
| 成绩查询 | `/zx marks [序号/名称]` — 图片渲染，序号 1=最新 |
| **逐题得分** | `/zx score [-s 学科] [序号/名称]` — 每小题得分表（见下） |
| 排名查询 | `/zx ranks [all] [序号/名称]` — 班级、年级排名，图片渲染（见下） |
| 考试列表 | `/zx exams [all]` — 图片渲染，默认本学年，all 查看全部 |
| **答题卡批改标注** | `/zx sheet <学科> [考试]` — 渲染批改标注长图（见下） |
| 手阅作业 | `/zx hw list [all]`、`/zx hw marks`、`/zx hw sheet` — 查询手阅作业（见下） |
| 账号绑定 | `/zx bind <用户名>`、`/zx unbind` — 一个智学网账号可绑定多个平台用户 |
| 成绩监听 | `/zx watch on [间隔]\|off` — 自动轮询，新成绩+新作业推送到私聊+群组 |
| 状态查看 | `/zx status` — 监听状态、配置账号、绑定关系与推送群组 |
| LLM 工具 | AI 可通过工具调用查询成绩、排名和答题卡（需绑定账号） |

**关于「序号/名称」**

- 序号从 1 开始（1 = 最新一场），**只在本学年范围内计数**，与 `/zx exams` 默认列表一一对应；超出范围会提示改用 `all` 后按名称查询。
- 名称支持模糊匹配，且在所有学年中搜索。如 `/zx marks 期中`。

## 逐题得分（小分表）

`/zx score` 把每个学科的每一道题的得分画成表，适合定位「哪几题丢分」：

| 命令 | 说明 |
|------|------|
| `/zx score` | 最新考试，全科逐题得分 |
| `/zx score 3` | 本学年第 3 场考试的逐题得分 |
| `/zx score 期中练习` | 按名称模糊匹配指定考试 |
| `/zx score -s 数学` | 只看单科（最新考试） |
| `/zx score -s 数学 2` | 单科 + 指定考试，参数顺序任意（`2 -s 数学` 等价） |

- **每行 8 题**，超出自动换行；末行补透明空格子保持列宽一致，不会因缺题拉伸。
- **红色 = 未得满分**，灰色小字为该题满分。得分与该题满分都齐全时才会判定扣分，缺任一项不标红。
- 学科名包含空格时用引号包裹，如 `-s "语文 阅读"`；未加引号时第一个词作为学科名，其余作为考试参数。
- `/zx score -s` 后面没写学科会直接给出用法提示；引号未闭合也会报错，不会静默截断。
- 表格为图片，渲染失败时自动降级为纯文本（题号:得分，同样按 8 题换行）。

**缺失值处理**（与网页端一致的保守口径）

| 情况 | 展示 |
|------|------|
| 服务端未下发该题得分 | 显示 `—`，不当作 0 |
| 服务端未下发该题满分 | 只显示得分，不拼 `x/满分`，也不判扣分 |
| 明确下发 `0` 或 `"0"` | 按真实 0 分显示 |
| 报告接口有分，但没有逐题小分 | 表头显示报告分，正文标注「暂无小分数据」 |
| 科目未扫描 | 保留状态标签，分数显示 `—` |

总分只在满足条件时才由小分汇总：得分需**每题都有**才求和，满分需**每题满分都齐全**才求和，避免半张卷子被当成完整总分。

## 排名查询

`/zx ranks` 查询最近一次考试的班级、年级排名，用法与成绩查询一致：

| 命令 | 说明 |
|------|------|
| `/zx ranks` | 最近一次考试的各科排名 |
| `/zx ranks <序号/考试名>` | 指定考试，支持序号和名称模糊匹配 |
| `/zx ranks all [序号/考试名]` | 显式全科查询，默认查询也包含未扫描科目 |

- 考试序号与 `/zx marks` 一致，从 1 开始（1 = 最新），如 `/zx ranks 01`
- 使用独立排名接口，仅读取服务端返回的班级排名 `clazzRank` 和年级排名 `gradeRank`，不根据百分位估算
- 缺失或无效排名显示「无排名」，未扫描科目保留相应状态标签
- 排名表格以图片发送，渲染失败自动降级为纯文本

## 答题卡批改标注渲染

`/zx sheet 数学` 会将答题卡原图渲染为带批注的 JPEG 长图，效果对齐智学网网页端：

- **顶部总分栏**：红色总分大字（如 `129 / 150 分`）+ 考试名/科目名
- **错题红框**：得分低于满分的题目区域红框圈出
- **题级标签**：`16题 5/16 -11`（红=有扣分，绿=满分）
- **分小问扣分明细**：`16(2): -3/3` 两列布局（来自 `stepDatas[].stepStandardScore` 满分与 `stepRecords` 得分）
- **老师逐点批注**：`+1` 等标注按原位绘制（markingContent spotMark）
- **卷面题号（v2.5.4）**：与原版网页一致，按 `answerRecordDetails[num-1]` 下标取记录、显示 `dispTitle` 卷面题号——语文等科目内部号与卷面号错位（如内部 11 号 = 卷面第 4 题）也能正确标注
- **选择题涂色（v2.5.1）**：与原版一致，学生所涂选项画空心框——答对青绿、答错红色，错在哪道一眼可见（v2.5.3 按 X/Y 双单位模型程序化校准：X=0.1953mm/px、Y=0.2117mm/px，三/四/七选项组全部精确套正，多选题逐选项画框）
- **每小题得分（v2.5.3）**：多小题解答区（如数学 21-23 题、英语语法填空 56-65）按原版网页端 `accountStepScoreStyle` 在裁切块**右上角**堆叠小表格 `21: -4/6`（黑题号+红/绿分数，超过 6 条自动分两列），不再画在横线上压住手写答案

坐标自适应三种答题卡模板：毫米坐标（A3 横 420 / A4 横 297 / A4 纵 210，由 locatePoint 自动判别）、设计分辨率像素 + 百分比坐标。

## 手阅作业查询

网页版没有手阅作业入口，但 zxbReport 接口对普通学生 web 会话开放。插件通过 `POST /zxbReport/report/*` 系列接口（token 放请求头）实现完整查询，用法与考试命令一致：

| 命令 | 说明 |
|------|------|
| `/zx hw list [all]` | 作业列表，默认最近 10 条，all 查看全部（自动翻页） |
| `/zx hw marks [序号/作业名]` | 作业各科成绩，序号与 list 一致 |
| `/zx hw sheet <学科> [作业]` | 作业答题卡批改标注长图，与 `/zx sheet` 同款渲染 |

- 作业序号与 `/zx marks` 一样从 1 开始（1 = 最新）
- 支持名称模糊匹配，如 `/zx hw marks 化学专题`
- 答题卡渲染复用考试批注管线（总分栏/错题红框/题级标签/逐点批注）；手阅作业通常无分步数据，只显示题级得分
- 监听开启时，发现新作业会自动推送作业名+各科分数（首次运行仅建立基线，不推送历史作业）
- 多页答题卡自动纵向拼接为一张长图（最大宽度 1600px）

## 成绩监听

| 命令 | 说明 |
|------|------|
| `/zx watch on` | 按配置间隔开启监听（默认 5 分钟） |
| `/zx watch on 10` | 开启并改为每 10 分钟检查一次 |
| `/zx watch off` | 停止监听 |
| `/zx status` | 查看是否运行中、间隔、各账号绑定与推送群组 |

- 监听是新成绩、新作业的**轮询**发现机制，不是智学网推送；间隔越小 API 调用越频繁，建议 ≥5 分钟。
- 每个智学网账号的更新推送到：该账号所有绑定用户的**私聊** + 该账号关联的 watch_groups **群组**。
- 账号在配置里被删除或改名时，`/zx status` 会标记 `[INVALID]`。

## 安装

将 `astrbot_plugin_zhixuewang.zip` 上传到 AstrBot 插件管理页面，或解压到 AstrBot 的 `data/plugins/` 目录。

依赖见 `requirements.txt`（`curl_cffi`、`opencv-python`、`numpy`、`pycryptodome`、`Pillow`），图片渲染依赖 AstrBot 自带的 t2i 能力。

## 配置

在 AstrBot WebUI 插件配置页面设置：

### 智学网账号列表

添加智学网用户名和密码。用户使用 `/zx bind <用户名>` 绑定后即可查询。用户名通常是学号或手机号。

> 账号只在插件配置里维护，用户**不能**自行添加；`/zx bind` 只是把平台用户与已配置账号关联。

### 成绩监听

| 配置项 | 说明 |
|--------|------|
| 开启新成绩监听 | 开/关（`/zx watch on` 也会写入此项） |
| 监听间隔 | 检查频率（分钟），最小 1 |
| 监听群组 | 按账号配置推送群组（需填 username + UMO） |

UMO 格式示例：`aiocqhttp:GroupMessage:123456`

### 监听推送逻辑

每个智学网账号的新成绩推送到：

1. 该账号所有绑定用户的**私聊**
2. 该账号关联的 watch_groups **群组**

## LLM 工具

插件注册了七个工具供 AI 调用：

* `zhixue_list_exams(user_id)` — 获取考试列表
* `zhixue_query_score(user_id, exam_name)` — 查询成绩
* `zhixue_query_ranks(user_id, exam_name)` — 查询班级、年级排名（省略考试名则查询最新考试）
* `zhixue_query_sheet(user_id, subject_name, exam_name)` — 查询答题卡（直接发图）
* `zhixue_list_homeworks(user_id)` — 获取手阅作业列表
* `zhixue_query_homework_score(user_id, homework_name)` — 查询作业成绩
* `zhixue_query_homework_sheet(user_id, subject_name, homework_name)` — 查询作业答题卡（直接发图）

通过 `on_llm_request` 钩子注入用户上下文（发送者 ID、被@用户 ID），AI 可自动识别查谁的成绩。对话里直接说「看看我的生物答题卡」也会命中 `zhixue_query_sheet` 并发图。

## 常见问题

**提示「账号 xxx 不在配置列表中」**
先在 WebUI 插件配置的「智学网账号列表」里添加该账号，再用 `/zx bind` 绑定。`/zx bind` 不会创建账号。

**逐题得分提示「该考试暂无答题卡小分数据」**
说明所有科目既没有逐题小分、也没有可用报告分——通常是小分尚未批改/发布。若报告分存在，插件会保留分数并标注「暂无小分数据」，不会丢弃。

**某些格子显示 `—`**
表示服务端未下发该题的得分或满分，与 0 分含义不同。只有服务端明确返回 `0` 才显示 0。

**成绩带「（含估算）」**
报告接口未返回该科分数时，插件会尝试从答题卡或趋势接口回退取分，并在表头注明含估算；拿不到就留空，不用排名百分位倒推。

**图片发不出来**
t2i 渲染失败会自动降级为纯文本，功能不受影响；若纯文本也没有，多半是账号未绑定或考试不存在。

## 技术要点

* **纯 HTTP 登录**：无 Playwright 依赖，服务器可用
* **三段式登录链路**：预登录 → SSO atLogin → SSO 换 ST
* **极验 v4 滑块**：自研 Geeked 求解器
* **手阅作业**：逆向 zxbReport POST 接口（token 必须放请求头），网页版无入口但接口开放
* **accounts.json 绑定系统**：支持一账号多平台绑定
* **考试列表缓存**：5 分钟 TTL，减少 API 调用
* **t2i 图片渲染**：黑白极简风格，失败降级纯文本
* **答题卡渲染**：PIL 批注，坐标自适应毫米/百分比模板，标签宽度自适应缩字
* **缺失值不伪造**：数值字段统一走可选解析，`None`/空串保持缺失，显式 `0` 保留为 0
* **小分汇总有条件**：得分需每题齐全才求和，满分需全部齐备才求和，半张卷子不出总分
* **成绩回退有优先级**：报告分 → 趋势区间估算 → 答题卡精确取分；估算值会标注，且不参与总分求和
